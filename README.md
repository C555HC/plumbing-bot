# Plumbing Bot

Идея сервиса для сантехнических мастеров и небольших бригад: Telegram-бот с AI-помощником и мини-ап с клиентской базой, заявками, календарём и историей работ.

Мастер ведёт дела обычными сообщениями или голосом. Клиент может описать проблему и договориться о выезде через чат. Для услуг с повторным обслуживанием сервис напоминает о следующем обращении.

## Документация

- [Контекст проекта для нового чата](docs/context.md): краткая идея, границы текущего этапа и правила параллельной работы.
- [Все идеи по сантехническому сервису](docs/product-ideas.md): аудитория, боли, выгоды, сценарии, возможные функции, интеграция с Авито и варианты предложения мастерам.
- [Исследование готовых основ и навыков](docs/research/README.md): открытые CRM, интерфейсные компоненты, календари, Telegram-инструменты и навыки для AI-агентов.

## Текущий этап

На 8 октября 2026 года здесь собраны идеи из обсуждения проекта и исследование возможных готовых основ. Их приоритеты и коммерческие предположения предстоит проверить на мастерах и клиентах.

Pipeline, техническая архитектура и план реализации пока не определены. Следующие этапы будем описывать и вести в этом репозитории.

Исследование Codex ведётся в ветке `codex/research-foundations`, отдельно от `main` и `feature/ideas-antigravity`. В рамках текущего этапа ветки не объединяем.
