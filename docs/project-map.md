# Карта проекта и принятые решения

Обновлено: 10 октября 2026 года. Ветка Codex: `codex/research-foundations`. На этом этапе сохраняем идеи, исследование и решения; реализация и pipeline ещё не начаты.

## Продукт

Telegram-бот с AI-помощником и мини-ап для сантехника или небольшой бригады. Клиент описывает проблему и записывается; мастер ведёт заявки, клиентов, оборудование и историю. Для подходящих услуг планируются напоминания о следующем обслуживании.

Подробности: [контекст](context.md), [продуктовые идеи](product-ideas.md).

## Что должны охватывать будущие проверки

- Клиент: описать проблему, уточнить данные, выбрать действительно доступное время, увидеть подтверждение, открыть запись из напоминания, перенести или отменить выезд.
- Сантехник: создать заявку сообщением, найти клиента и адрес, посмотреть историю, изменить время, завершить работу и назначить следующее обслуживание.
- Общие случаи: пустые списки, ошибки сохранения, потеря сети, повторные нажатия и работа на телефоне.

Навык проверки фронтенда не подтверждает сам по себе корректность серверных прав, очереди и реальной доставки Telegram. Для этих частей понадобятся отдельные проверки.

## Кандидаты, которые пока не утверждены

| Часть | Рабочая рекомендация исследования | Статус |
| --- | --- | --- |
| Компоненты интерфейса | shadcn/ui; TanStack Table для списков | Кандидаты, пользователь запросил объяснение shadcn |
| Готовая CRM | Atomic CRM или собственный компактный интерфейс | Решение не принято |
| База | PostgreSQL; Supabase как вариант готовой платформы и панели | Рекомендация Codex, не решение пользователя |
| Минимальный прототип | SQLite при одном сервере и небольшой нагрузке | Альтернатива, не установка |
| Фоновые напоминания | pg-boss при Node.js/PostgreSQL; либо Supabase Cron + Queues | Альтернативы, одновременно не выбираем |
| Telegram | Bot API + grammY при TypeScript; aiogram при Python | Язык и библиотека не выбраны |
| Скиллы базы | supabase-postgres-best-practices; при выборе Supabase — официальный supabase skill | Найдены, пока не утверждены |

Исследование: [база, фоновые задачи и Telegram](research/database-and-reminders.md), [общая подборка](research/README.md).

## Работа с репозиторием

Codex сохраняет материалы только в `codex/research-foundations`. Ветки `main` и `feature/ideas-antigravity` не объединяем. Эта карта — точка входа для восстановления принятых решений после очистки чата; новые прямые указания пользователя могут изменить решения и этап работы.
