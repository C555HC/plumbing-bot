# Исследование готовых основ и навыков

Дата исследования: 8 октября 2026 года. Ветка: `codex/research-foundations`.

Это хранилище найденных материалов и оценок для будущего выбора. Ничего из подборки не установлено и не встроено в приложение. Pipeline и окончательный стек не определены.

## Быстрый результат

| Задача | Кандидаты для первого изучения | Предварительная оценка |
| --- | --- | --- |
| Взять небольшую готовую CRM и адаптировать | Atomic CRM | Самый интересный кандидат на проверку: понятная CRM-основа и MIT; сантехнические сценарии ещё придётся добавлять |
| Сделать собственный компактный интерфейс из готовых деталей | shadcn/ui + TanStack Table; при необходимости React Admin | Альтернатива форку CRM, если узкий мобильный интерфейс важнее большого набора готовых функций |
| Изучить предметную область выездного сервиса | Dolibarr Interventions; Beveren FSM | Ближе к заявкам и работам мастеров, но требуют более тяжёлой основы |
| Изучить готовую универсальную CRM | EspoCRM; Frappe CRM; Twenty | Полезные кандидаты и интерфейсные примеры; лицензии и объём адаптации различаются |
| Выбор даты и расписание | DayPicker; FullCalendar Standard; React Big Calendar | Выбор даты, календарь выездов и запись на доступное время — разные задачи |
| Навык для компонентов и таблиц | Официальный shadcn skill | Наиболее предметный навык для сборки интерфейса из shadcn/ui |
| Дизайн и проверка удобства | frontend-design; Impeccable; Vercel web-design-guidelines | Выбирать подходящие навыки под задачу, проверять результат на мобильных сценариях мастера |

Все оценки в последнем столбце — вывод исследования, а не готовый выбор продукта.

## Как проводилась проверка

Проверены 27 публичных репозиториев через GitHub API: адрес после переадресаций, состояние архива, ветка по умолчанию, SHA и дата последнего коммита этой ветки, README и корневые лицензии. Для выбранных навыков дополнительно прочитаны `SKILL.md` и доступные лицензии навыков. Использованы официальные сайты авторов библиотек и документация платформ.

Подробный код, зависимости, работа локального развёртывания, интерфейс на телефоне и совместимость конкретных версий не проверялись. «Не архивирован» и свежий коммит сами по себе не доказывают качество поддержки.

Снимок ветки по умолчанию нужен для воспроизводимости исследования. Ветка `develop` или `main` не обязательно является стабильной версией для будущего запуска.

Ссылки на README и лицензии закреплены на проверенных коммитах. Сайты документации могут меняться; перед внедрением их нужно перечитать.

## На что обратить внимание при возвращении к материалам

- Atomic CRM — основа общей CRM, а не готовый Telegram-сервис сантехника. Авторизация, разделение данных независимых мастеров, оборудование, запись и напоминания требуют проверки и адаптации.
- У Twenty смешанное лицензирование; отдельные пакеты имеют MIT, ядро — AGPL с дополнительным разрешением для приложений, Enterprise-файлы — коммерческую лицензию.
- AG Grid Community и Enterprise, FullCalendar Standard и Premium нельзя считать одной бесплатной поставкой.
- `calcom/cal.com` при проверке переадресуется на Cal.diy. Сам README Cal.diy рекомендует личное использование вне production; это не выбранная основа коммерческого сервиса.
- `openai/skills` помечен устаревшим. Для актуальных примеров OpenAI найден `openai/plugins`; условия конкретного пакета нужно проверять отдельно.
- Готовый SDK для Avito не выдаёт права API и не снимает ограничения аккаунта.
