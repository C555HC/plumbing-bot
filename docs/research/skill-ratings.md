# Оценки скиллов для нашего проекта

Дата: 10 октября 2026 года. Оценки Codex по прочитанным инструкциям и задачам проекта, без испытания навыков на нашем приложении. Это оценка применимости, а не доказанная эффективность или рейтинг качества автора.

Критерии: мобильная CRM мастера, понятные заявки и клиентские карточки, формы записи, скорость разработки и проверка пользовательских сценариев. 9–10 — высокий приоритет; 7–8 — полезный помощник; 5–6 — дополнительный инструмент. Оценки отражают пользу при разработке, а не необходимость установки на текущем этапе сбора идей.

## Основная подборка

| Скилл | Оценка | Как поможет именно нам | Ограничение |
| --- | --- | --- | --- |
| Официальный shadcn skill | 9/10 | Сборка карточек клиентов, форм заявок, диалогов, фильтров и таблиц из согласованных компонентов | При выборе shadcn; при другом UI-стеке оценка существенно ниже |
| Vercel web-design-guidelines | 9/10 | Проверка форм, ошибок, фокуса и взаимодействий; полезна для интерфейса мастера на телефоне | Аудит по правилам не заменяет проверку с реальными мастерами |
| Anthropic webapp-testing | 9/10 | Позволяет агенту проверять запись, поиск клиента, сохранение изменений и состояния интерфейса через Playwright | Когда появится приложение; работу Telegram и очереди напоминаний проверять отдельно |
| Anthropic frontend-design | 8/10 | Единый визуальный язык, читаемость и иерархия информации на экранах | Часть инструкций о выразительном дизайне страниц менее важна для рабочей CRM |
| Impeccable | 8/10 | Аудит и улучшение интерфейса; кандидат для последовательной доработки экранов | Пересекается с другими дизайн-навыками; его установщики и hooks ещё не проверены |
| Vercel react-best-practices | 8/10 | Более быстрая загрузка, разумная работа с данными и компонентами мини-апа | При выборе React; некоторые Next.js-правила могут не относиться к нашему стеку |
| Vercel composition-patterns | 6/10 | Повторное использование общих карточек, форм и действий | Полезность возрастёт при росте интерфейса; для первых простых экранов второстепенен |
| UI UX Pro Max | 6/10 | Дополнительные варианты палитр, шрифтов и UX-паттернов | Много общих возможностей; часть пользы уже закрывают frontend-design и Impeccable |

## Предварительный приоритет

При выборе React/shadcn: один shadcn-навык, frontend-design для визуального направления, web-design-guidelines для проверки. После появления рабочих экранов — один навык тестирования, при необходимости react-best-practices. Остальные подключать под конкретную задачу.

Ни один из перечисленных навыков сам не реализует понимание AI-команд, права доступа к клиентским данным, серверную запись, повторные напоминания и Avito-интеграцию. Эти части требуют отдельного проектирования и проверки. Навыки не устанавливались и не активировались.
